# Git Practice

## About This Repository
This repository is created to practice basic Git and GitHub operations.

## Git Commands
- git init: Initialize a Git repository.
- git clone: Copy a repository.
- git add: Stage changes.
- git commit: Save changes.
- git push: Upload changes to GitHub.
- git pull: Download changes from GitHub.

## Branching
Branches allow developers to work on different features independently.

## Pull Request
A Pull Request is used to propose changes and review code before merging.
